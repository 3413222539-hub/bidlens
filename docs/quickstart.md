## 无 API Key 体验

在项目根目录打开 PowerShell，执行以下命令。已有虚拟环境和依赖时，可以直接从第三行开始。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts/seed_revision_demo.py
.\.venv\Scripts\python.exe -m uvicorn web_app:app --port 8780
```

浏览器打开 [本地工作台](http://127.0.0.1:8780)。演示使用虚构的招标文件和澄清公告，初次生成时预置旧确认。默认启动命令使用本地模式。

| 操作 | 预期结果 |
|---|---|
| 点击「体验无 Key 演示」 | 打开原文件的第 2 包自查，可以看到已确认的最高限价、投标截止时间和证照要求。 |
| 点击「关联演示公告并查看待复核」 | 页面直接筛出第 2 包的三项变更。最高限价由 75 万元改为 80 万元，截止时间由 9 月 22 日 14:30 改为 9 月 28 日 14:30，原食品经营许可证要求取消。 |
| 展开「最高限价」，点击两侧引用 | 分别打开原招标文件第 1 页、澄清公告第 1 页。展开条目还能看到旧确认人和时间。 |
| 点击「确认已核对」 | 该项从待复核筛选中消失。切回「全部状态」可查看本次确认和旧确认记录。 |
| 在标包下拉框切到第 1 包，选「全部状态」 | 第 1 包的限价和截止时间继续显示已确认。 |
| 切回第 2 包，点击「导出 PDF」 | 打开打印视图，选择「另存为 PDF」或「Microsoft Print to PDF」，保存完整的标包清单。 |

按钮显示「查看第 2 包待复核」时，说明当前浏览器已关联演示公告。想再次查看原清单，可到「文档问答」，将「关联澄清公告」改为「选择已导入的 PDF」。重复生成演示文件会保留已有的确认记录。

## 复核自己的招标文件

1. **导入 PDF。** 在首页选择本地文件或填入公开 PDF 直链，等待解析和风险清单生成。真实文档解析需配置 MinerU，开放问答和模型生成清单需配置模型服务。
2. **查风险和评分。** 打开「风险清单 → 按标包自查」，选择标包并展开条目。也可以在「文档问答」问「第 2 包有哪些技术评分项？」，逐项查看分值与引用。某些综合评分表包含报价分，页面会标明评分类型。
3. **关联澄清公告。** 先导入公告，再切回原招标文件。在「文档问答」选中公告并点击「查看变更」。回到标包自查后，可筛选「变更后待复核」。遇到原值冲突或范围不明确时，按提示回原文核对。
4. **确认并导出。** 确认动作表示复核员已核对该条。「适用」「不适用」「待核对」表示条款对当前标包的适用性。导出的打印视图包含完整标包清单，即使页面正在筛选待复核项。

## 当前版本范围

每份原招标文件可关联一份澄清公告。复核联动覆盖最高限价、投标截止时间和可识别的证照资格变更。评分表遇到未识别格式时，请用引用对照原件。演示重点是变更复核，演示文件没有评分表。

若首页没有演示按钮，请确认已在本项目目录运行种子脚本，并刷新页面。若导出未打开，检查浏览器是否拦截了新标签页。真实文件的服务配置见 [项目 README](../README.md)，评测与样本说明见 [评测目录](../eval/README.md)。
