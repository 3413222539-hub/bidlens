表内为 API 返回的实际 token，包含在线查询向量，另有两个基线共享的文档向量索引开销 83,965 输入 token。评委调用单独记录。供应商的实际计费单价未核实，人民币费用留空。该样本仅代表本次运行。

## 复现

按冻结清单下载并核对 PDF 指纹。导入文档后创建一份 JSON 映射，将 `pingnan`、`yancheng`、`cpu` 分别映射到本机导入 ID。配置回答服务后执行：

```powershell
python eval/compare_holdout.py --manifest eval/holdout_v1.json --mapping data/holdout-v1/mapping.json --output data/holdout-v1/run-new.json --embedding-model qwen3.7-text-embedding-flash --workers 3
```

原始输出含证据片段，保存在本地忽略目录。可通过 `--prices` 提供核实后的价格 JSON，格式为 `{"models":{"模型ID":{"input_per_million":1,"output_per_million":4}}}`，其中数字仅作格式示例。修复已发现的问题后，应另选新文件验证泛化。
